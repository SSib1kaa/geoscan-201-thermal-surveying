# geoscan-201-thermal-surveying
Thermal and night vision surveying system for Geoscan 201 drone. Features infrared camera integration, thermal image processing, and night vision capabilities for geodesy applications.
Система тепловизионной съемки и ночного видения для БПЛА Geoscan 201. Включает в себя: интеграцию инфракрасной камеры, тепловизионную обработку изображений и возможности ночного видения для геодезических целей.
